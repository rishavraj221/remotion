# How the AI Projects System Works

## 🎯 Overview

The AI projects system uses a **smart loading mechanism** that:
- ✅ Shows newly generated projects immediately
- ✅ Resets to placeholder on browser refresh/restart
- ✅ Never overwrites the core `index.tsx` file
- ✅ Keeps all generated files for history

## 📂 File Structure

```
ai-projects/
├── index.tsx                              # [PERMANENT] Smart loader (never overwritten)
├── current-project.tsx                    # [TEMPORARY] Points to active project
├── generated-project-1234567890.tsx       # [ARCHIVE] Generated files
├── generated-hello-world-1234567891.tsx   # [ARCHIVE] ...
└── generated-animation-1234567892.tsx     # [ARCHIVE] ...
```

## 🔄 How It Works

### 1. Initial State (Fresh Start)

When you first open Remotion or refresh the browser:

```
index.tsx (loads)
    ↓
    Tries to import('./current-project')
    ↓
    ❌ File doesn't exist (gitignored)
    ↓
    Shows PlaceholderProject
```

**What you see:** The welcome screen with instructions.

### 2. After AI Generates Code

When the AI generates a new video:

```
User: "Create a video with text 'Hello' that fades in"
    ↓
Backend generates code
    ↓
Creates: generated-hello-1234567890.tsx    ← Full component
    ↓
Creates: current-project.tsx              ← Re-exports above file
    ↓
Remotion hot-reloads
    ↓
index.tsx detects current-project.tsx
    ↓
Loads and renders the generated component
```

**What you see:** Your newly generated animated video!

### 3. After Browser Refresh

When you refresh the browser:

```
Browser refreshes
    ↓
index.tsx loads again
    ↓
Tries to import('./current-project')
    ↓
❌ File doesn't exist (gitignored, not in version control)
    ↓
Shows PlaceholderProject again
```

**What you see:** Back to the welcome screen.

### 4. Viewing Previous Projects

All generated files are saved! To view an old project:

```
1. Find the file: generated-{name}-{timestamp}.tsx
2. Manually edit current-project.tsx to import it
3. Or copy the old code and generate a new version
```

## 📝 The Files Explained

### `index.tsx` - The Smart Loader

```typescript
export const AIProject: React.FC = () => {
  // 1. Try to load current-project.tsx
  // 2. If found, render it
  // 3. If not found, show placeholder
};
```

**Key features:**
- ✅ Never gets overwritten
- ✅ Always stays in version control
- ✅ Dynamically loads current project
- ✅ Graceful fallback to placeholder

### `current-project.tsx` - The Active Project Pointer

```typescript
// Auto-generated: Points to the currently active project
import AIGeneratedComponent from './generated-hello-1234567890';

export { AIGeneratedComponent };
export default AIGeneratedComponent;
```

**Key features:**
- ✅ Created by backend when AI generates code
- ✅ In `.gitignore` (not tracked)
- ✅ Resets on fresh start
- ✅ Always points to latest generation

### `generated-*.tsx` - The Generated Components

```typescript
// Full Remotion component generated by AI
import React from 'react';
import {AbsoluteFill, useCurrentFrame, interpolate} from 'remotion';

export const AIGeneratedComponent: React.FC = () => {
  // Your animation code here
};
```

**Key features:**
- ✅ Complete working Remotion components
- ✅ Saved permanently (in `.gitignore` but on disk)
- ✅ Can be manually edited
- ✅ Timestamped for history

## 🔧 Backend Implementation

The backend `writeAIProject` function does:

```typescript
1. Generate filename: `generated-${safeName}-${timestamp}.tsx`
2. Write full component code to that file
3. Create/update `current-project.tsx` to re-export it
4. Log success
5. Send confirmation to frontend
```

## 🔒 Why This Design?

### Problem with Old Approach

**Old way:** Overwrite `index.tsx` every time
- ❌ Loses the original placeholder
- ❌ Can't reset to clean state
- ❌ Messy git history
- ❌ Hard to recover from bad generations

### New Approach Benefits

**New way:** Keep `index.tsx` static, use `current-project.tsx` as pointer
- ✅ Preserves original placeholder
- ✅ Automatic reset on fresh start
- ✅ Clean git history
- ✅ All generations saved
- ✅ Easy to recover/browse history

## 🎯 Key Principles

1. **Separation of Concerns**
   - `index.tsx` = Loader logic (permanent)
   - `current-project.tsx` = Active project (temporary)
   - `generated-*.tsx` = Actual code (archived)

2. **Graceful Degradation**
   - If `current-project.tsx` missing → show placeholder
   - If import fails → show placeholder
   - Never breaks, always has fallback

3. **Developer Friendly**
   - All generated files kept for reference
   - Can manually edit any file
   - Can recover old projects
   - Clean git workflow

4. **User Friendly**
   - Fresh start = clean slate
   - New generations = instant update
   - No confusion about state
   - Clear feedback

## 🐛 Troubleshooting

### "Still showing old project after refresh"

**Cause:** `current-project.tsx` exists when it shouldn't

**Solution:**
```bash
rm packages/example/src/ai-projects/current-project.tsx
```

### "Can't see newly generated video"

**Cause:** Hot reload didn't trigger or import failed

**Solution:**
1. Check console for errors
2. Verify `current-project.tsx` exists
3. Refresh browser
4. Check file permissions

### "Want to keep a generated video permanently"

**Solution:**

Option 1 - Copy to new component:
```bash
cp generated-cool-video-123.tsx MyCoolVideo.tsx
# Edit MyCoolVideo.tsx to rename export
# Import in Root.tsx
```

Option 2 - Create new composition:
```typescript
// In Root.tsx
import MyCoolVideo from './ai-projects/generated-cool-video-123';

<Composition
  id="my-cool-video"
  component={MyCoolVideo}
  ...
/>
```

## 📊 File Lifecycle

```
Generate → Write to disk → Update pointer → Hot reload → Display
   ↓           ↓               ↓               ↓           ↓
Backend    generated-*.tsx  current-        Remotion    User sees
creates                     project.tsx     detects     video
code                        updated         change
```

**On refresh:**
```
Browser refresh → current-project.tsx gone → index.tsx loads placeholder
```

**On next generation:**
```
New generation → New generated-*.tsx → current-project.tsx recreated → New video displays
```
